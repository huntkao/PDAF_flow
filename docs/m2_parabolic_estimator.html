M2 · ParabolicDepthEstimator

從 cost sequence 求 sub-pixel 視差與信心值

PDAF pipeline 的第二模組（M2）。輸入是 M1 對每個候選位移算出的相位匹配成本曲線，輸出一個 sub-pixel 的 disparity 與一個 0–1 的 confidence。原理：拋物線內插找谷底，再由谷的深度、曲率、有無競爭谷三個因子評估可信度。

M1 相位 cost→M2 深度估測→M3 DCC→VCM

成本曲線在真實視差附近有一個谷；M2 的工作就是精準定位這個谷底、並評估它有多可信。

輸入

matching cost sequence：越吻合，成本越低

M1 把左右相位像素相對位移 s，逐點算 SAD（絕對差和）。位移對齊真實視差時左右最吻合、成本最低，形成一條有谷的曲線 cost[s]。

離散樣本只在整數位移上取得；最低的整數點（橘）是視差的粗估，但真正的谷底通常落在兩個樣本之間。

核心 · sub-pixel 內插

用谷底三點擬合拋物線，頂點即 sub-pixel 視差

取最低整數點與左右鄰點 c₋₁, c₀, c₊₁，唯一穿過三點的拋物線其頂點偏移量：

δ = ½·(c₋₁ − c₊₁) / (c₋₁ − 2c₀ + c₊₁)
  • 整數最小點 s = 2，成本 0.056
  • 三點 = 0.064, 0.056, 0.123
  • δ = −0.394 → 視差 = 2 + δ = 1.606
  • 真值 1.600，誤差 0.006（sub-pixel 精度）

confidence · 三因子

深度 × 無歧義 × 曲率

confidence = depth × unamb × (0.5 + 0.5·sharp)
  • depth = 1 − c_min/c̄：谷相對平均有多深（尺度不變）
  • sharp = 1 − 2c₀/(c₋₁+c₊₁)：谷底轉得多急（曲率）
  • unamb：有沒有競爭谷（下一張）
  • 圖中兩谷深度相近，但窄谷 0.75 > 寬谷 0.53——曲率反映定位精度

曲率是輕度折扣（最多對折）：寬但清楚的谷估值仍正確、只是較不精準，不該打死。

unamb · 次低點檢查

basin-walk：只有被山脊隔開的谷才算「競爭」

unamb 找主谷以外的最低成本，越接近谷底越歧義。關鍵是「以外」怎麼定義——排除主谷整段單調 basin（從谷底往兩側走到成本回升為止），而非固定寬度，否則寬谷會把自己的坡誤判成第二個谷。

寬單峰谷：整段 basin（陰影）就是全部 → 無競爭谷 → unamb = 1，conf 0.56

雙峰（aliasing）：山脊外還有深谷（橘）→ unamb → 0，conf 0.04——即使主谷又深又尖

退化情況

邊界與無紋理的安全處理

執行期不丟例外，只降級——這是實機 AF 的要求。

最小點落在搜尋範圍邊界 → 真谷可能在範圍外，不做內插、confidence ×0.5

曲線近乎全平（無紋理／c̄≈0）→ 無谷可尋，回傳 invalid、confidence 0

對應程式碼

estimate() 的決策流程

// src/algo/parabolic_depth_estimator.cpp
DepthEstimate estimate(const CostSequence& cost){
  if(v.size()<3 || valid_samples<=0) return {}; // invalid
  mi=argmin(v); mean=average(v);
  if(mean < 1e-6) return {};              // 無紋理
  depth  = clamp(1 - v[mi]/mean, 0,1);      // 深度
  [lo,hi]= basin_walk(v, mi);               // 主谷 basin
  second = min(v outside [lo,hi]);          // 次低點
  unamb  = clamp((second-v[mi])/(mean-v[mi]),0,1);
  if(mi==0 || mi==last)                     // 邊界
    return {shift_min+mi, depth*unamb*0.5f, true};
  δ      = 0.5*(c₋₁-c₊₁)/(c₋₁-2c₀+c₊₁);     // sub-pixel
  sharp  = clamp(1 - 2c₀/(c₋₁+c₊₁), 0,1);   // 曲率
  conf   = depth * unamb * (0.5+0.5*sharp); // 三因子
  return {shift_min+mi+δ, conf, true};
}
  • 純函式、無狀態；一條 cost 曲線進、一個估測出
  • 頂點內插把整數精度提升到 sub-pixel
  • 信心 = 深度 × 無歧義 × 曲率：分別擋掉離焦/無紋理、aliasing 歧義、寬谷低精度
  • basin-walk 讓寬谷不被誤判成歧義
  • 退化路徑全部回傳合法結果，絕不丟例外
