單次自動對焦：三種物距的收斂軌跡

同一套 pipeline（M1 相位匹配 → M2 disparity/confidence → M3 DCC→VCM step）在三個場景各跑一次 pdaf_cli。每條線是鏡頭 VCM step 隨 sensor frame 的變化，收斂到各自的合焦位置（虛線）。

VCM step 收斂

量測 → 移動 → settle → 複查 → 合焦，全程 5 個 frame

對焦方向

近距 disparity 正（+6.0，鏡頭往前 300→600）、遠距 負（−9.3，往後 600→130）。符號直接指出鏡頭該往哪走。

量測精度

初始量測對上真值誤差 < 0.07 disparity、confidence 0.93–0.98，即使遠距 −9.3 已近 ±16 搜尋窗邊緣。

殘留誤差

遠距落在 133（真值 130，3 step）：單一 DCC 增益對大離焦線性外插的偏差，仍在合焦門檻內。多錨點 DCC 表可消除。

逐 frame 紀錄
